# powerBI-Mobile-Sales-Data-Project
Developed an interactive Power BI dashboard analyzing ₹76.92 Cr in mobile sales (19K units, 4K transactions) using Power Query and DAX. Built dynamic slicers, city maps, and brand/payment visuals to help optimize stock for top-selling models (iPhone SE, OnePlus Nord), target high-demand cities, and time promotions for peak sales months.
